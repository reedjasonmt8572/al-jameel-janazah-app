## About the Companion

Al-Jameel Janazah Companion offers Muslims a clear web-based way to access information about the Janazah process. The application combines practical guidance, educational content, and helpful tools so that relevant resources can be found from one place.

It is designed for individuals, families, and communities who want dependable, organized Janazah information before it is needed or during an urgent situation. By bringing these materials together, the companion supports both preparation and immediate reference.
